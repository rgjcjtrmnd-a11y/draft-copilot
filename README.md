# MatchupMind — installable web app

Compiled build output only, so that GitHub Pages can serve it. No source code here;
the source lives in a separate private repository.

**Open it:** https://rgjcjtrmnd-a11y.github.io/draft-copilot/

On an iPhone, open that link in Safari, then Share → **Add to Home Screen**. It launches
fullscreen like an installed app, and the draft board works with no network — the player
board, league rules and recommendation engine are all compiled into the page.

Signing in, syncing and live news additionally require the backend, which is not part of
this deployment.
