# Draft Copilot — installable web app

This repository holds only the **compiled build output** of the app, so that GitHub Pages
can serve it. There is no source code here; the source lives in a separate private
repository.

**Open it:** https://rgjcjtrmnd-a11y.github.io/draft-copilot/

On an iPhone, open that link in Safari, then Share → **Add to Home Screen**. It launches
fullscreen like an installed app and the draft board works with no network — the player
board, the league rules and the recommendation engine are all compiled into the page.

Signing in, syncing and live news additionally require the backend, which is not part of
this deployment.
